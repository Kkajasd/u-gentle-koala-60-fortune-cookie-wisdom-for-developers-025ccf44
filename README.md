A program that writes one original line of fortune-cookie wisdom for a software developer to `/output/entry.txt`. The line is 87 characters, inside the 120-character gate, and is written deterministically with no extra output.

The fortune: "The line you delete with confidence is the line the next outage will quote back to you."

## Run it

```sh
node main.ts
```
